# Project_TiO2_fluxionality

**inputs and scripts should be placed in the same directory to start the calculation**

**inputs**:

TD-DFT excitation calculations are performed with CP2K along the AIMD trajectory generated in step 1. This folder contains the input files required to run the excited-state calculations. As a case example, the provided files correspond to isomer 1 at 100 K.

The `dynamics_AIMD-aligned.xyz` file contains the aligned AIMD trajectory used as input for the TD-DFT calculations.

The `es_diag_temp.inp` file is the CP2K input template where the TD-DFT options are defined. This file is written for the 100 K calculation of isomer 1 and should be modified accordingly for other systems or temperatures.

**scripts**:

The `distribute_jobs.py` script should be modified by specifying the initial and final steps of the trajectory, as well as the number of jobs. Libra will split the trajectory according to these values and will create the specific folders for each job.

The `run_template.py` file contains the instructions required to run the molecular orbital overlap calculations.

The `run.py` file is generated from `run_template.py`, with the initial and final trajectory steps automatically filled according to the requested number of jobs and the selected trajectory range.

The `submit_template.slm` file is the Slurm submission template used to submit each job to a HPC system. This file runs the corresponding `run.py` script generated for each trajectory segment.

The `vmd_cube_template.tcl` file is the VMD input template. This input is modified by Libra, but only the `mol load cube` and rendering lines, such as `render Tachyon ...`, are changed. A customized VMD input template can be generated by opening VMD on your local computer and selecting `File` → `Log Tcl commands to file...`; VMD will then append all the commands needed to reproduce the image into a file.

To start the TD-DFT calculations, combine the required input and script files in the same directory and run:

**python distribute_jobs.py**

**outputs**:

Including all step 2 results for the full 3000-geometry trajectories would be extremely difficult due to the large file sizes. Therefore, only the results for the last 500 geometries are provided. These correspond to geometries 2500–3000 of the AIMD trajectories.

The `outputs` directory contains two subdirectories, one for each temperature: `100K` and `300K`. Each subdirectory contains the compressed `.bz2` files with the TD-DFT results for isomer 1 at the corresponding temperature.

The compressed files include the regular CP2K `.log` output files, together with the energies of the KS orbitals (`E_ks_*`), the molecular orbital overlaps (`S_ks_*`), and the molecular orbital time-overlaps (`St_ks_*`).

For the 300 K case, the output folder also includes some of the generated figures reported in the manuscript, such as the S1 energy evolution, the S1–S10 excited-state energy evolution, and the correlation between the S1 energy and the Ti_flux–O_flux distance.

To unpack the compressed output files, decompress each `.bz2` file separately. For example:

**tar -xvjf isomer1_100K_logfiles.bz2**

**tar -xvjf isomer1_100K_res_part1.bz2**

**tar -xvjf isomer1_300K_logfiles.bz2**

**tar -xvjf isomer1_300K_res_part1.bz2**

Repeat the same command for the remaining `res_part*.bz2` files.

-------------

Take into account that the `inputs` and `scripts` folders contain the data and templates for the 100 K case of isomer 1. The workflows described in these files can be adapted to generate the full set of results over longer trajectories containing up to 3000 geometries.
